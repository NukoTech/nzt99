> Part of the NukoTech open skill set ([github.com/NukoTech](https://github.com/NukoTech)). MIT licensed. (c) 2026 Nuko Technologies LLC.

## What it is

Six-engine anticipatory intelligence discipline for complex strategic analysis. GOVERNOR MODE self-activates on any task requiring prediction, anticipation, causal reasoning, or multi-variable strategic thinking. EXECUTOR MODE runs the full NZT99 compound loop: Psychology Engine (metacognitive strategy selection) → Probability Engine (calibrated forecast + cross-domain pattern matching) → Philosophical Engine (counterfactual causal reasoning + intervention design) → Skeptic Engine (adversarial self-challenge) → Reason Learning (step-level self-scoring) → Memory (compound pattern storage). Not a single-pass analysis — a compound intelligence loop where each pass strengthens the next. MUST activate on: anticipate, predict, forecast, what if, counterfactual, what happens if, what would happen, cause and effect, causal, second order, third order, consequences, cascade, intervene, leverage point, 5D chess, NZT, NZT99, strategic, proactive, probability, pattern recognition, cross-domain, compound analysis, scenario planning, war game, red team a decision, limitless, multi-variable, sensitivity analysis, see around corners, preemptive, what's coming. Also fires on: any high-stakes strategic decision involving 3+ variables, any request to anticipate competitor/market/client behavior, any planning task where consequences cascade beyond the obvious. If the situation requires seeing ahead rather than just responding — this fires.

> **Runtime not included; this is the method skill.** NZT99 ships here as a method skill only. No runtime, engine code or service is bundled.

## Install


```bash
git clone https://github.com/NukoTech/nzt99.git
```


Copy the skill folder into your agent's skills directory (for example `~/.claude/skills/` for Claude Code, or your platform's equivalent). Each `SKILL.md` has YAML front matter (`name`, `description`) that agent runtimes use to decide when to load it.

## Usage

Ask your agent for the task described above; the runtime loads the skill when the request matches its description. You can also paste the main file into a system prompt or custom-instructions field.
