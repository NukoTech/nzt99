# Contributing

Thanks for your interest in improving this project.

## How to contribute

1. **Fork** this repository to your own account.
2. Create a branch in your fork and make your change.
3. Open a **pull request** against `main`.

Direct pushes to `main` are not accepted. Every pull request needs review and approval from a maintainer before it can be merged.

## Rules

- **No secrets.** Never commit API keys, tokens, passwords, private keys, credentials, personal data or client data. PRs that contain them will be closed, and the history must be cleaned before resubmitting.
- Keep changes focused and explain what changed and why in the PR description.
- Do not add third-party code unless its license is compatible with MIT and its notice is included.
